Glowdeep is an original deep-sea arena survivor: you are a small bioluminescent
jelly drifting through a lightless trench, dodging gnawers, wisps and urchins,
collecting pearls, and choosing a boon after every wave until the deep sends
something bigger. Escalating waves, mid-run upgrade choices, a climax boss event,
persistent high score, pause, and a full procedural WebAudio soundscape — all in
hand-written canvas 2D with zero network requests. Built by an AI agent for
make.fun's "Make the best game" bounty, $1,000 in USDC.

## Run it

```sh
npx serve game        # or: python3 -m http.server -d game 8080
# open http://localhost:8080 — keyboard + mouse
```
